# paint-app

ブラウザで動く、レイヤー対応のペイントアプリです。アイビスペイントのような使い心地を目指しています。

## 起動方法

`index.html` をブラウザで開くだけで使えます。

オフライン対応(ホーム画面への追加)を使う場合は、HTTP サーバーから配信してください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## 機能

- ツール: ブラシ(ペン / エアブラシ)、消しゴム、ぼかし、バケツ(範囲塗り)、スポイト、直線、四角形、楕円、移動
- 描き心地: 筆圧(ペン入力)、手ぶれ補正、ブラシサイズの円カーソル
- 表示: ホイールやピンチでの拡大・縮小、回転、移動、画面に合わせる
- カラー: 色相リングと彩度・明度の四角、HEX 入力、最近使った色、パレット(追加・削除)
- レイヤー: 追加、複製、並べ替え、下と結合、名前変更、消去、削除、表示/非表示、ロック、不透明度、合成モード、クリッピング、透明部分の保護、サムネイル、背景(白 / 透明)
- 元に戻す / やり直す: 描画とレイヤー操作の両方に対応
- 保存: ブラウザ内への自動保存、プロジェクトファイル(`.paintproj`)の保存と読み込み、PNG 書き出し(背景透過可)
- 新規キャンバス: サイズを選んで作成
- スマホ・タブレット: 下部バーと下から出るパネル、2本指タップで元に戻す、3本指タップでやり直す、長押しでスポイト、ペン使用時は指を移動専用に切り替え

## 操作

| 操作 | キーボード / タッチ |
| --- | --- |
| ツール切り替え | B ブラシ / E 消しゴム / S ぼかし / G バケツ / I スポイト / L 直線 / U 四角形 / O 楕円 / H 移動 |
| ブラシサイズ | `[` `]` |
| 回転 | R / Shift+R |
| 移動 | Space を押しながらドラッグ、中ボタンでドラッグ |
| スポイト | Alt を押しながらクリック、長押し |
| 拡大・縮小 | ホイール、ピンチ、Ctrl + `+` / `-`、Ctrl+0 で画面に合わせる |
| 図形 | Shift で縦横比固定・45°刻み、Alt で中心から |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Shift+Z・Ctrl+Y、2本指タップ / 3本指タップ |
| プロジェクト | Ctrl+S 保存 / Ctrl+O 開く |

## ファイル構成

- `index.html` 画面の構造とアイコン(SVG)
- `styles.css` 見た目(幅 900px 未満はスマホ向けの配置)
- `js/app.js` 描画、表示操作、レイヤー、入力、保存などの本体
- `js/color.js` 色の変換と色選択
- `js/history.js` 元に戻す / やり直すの履歴
- `js/fill.js` バケツの範囲塗り
- `js/storage.js` 自動保存(IndexedDB)とファイルの読み書き
- `sw.js`, `manifest.webmanifest`, `icons/` オフライン対応とホーム画面用アイコン
