操作ガイド

タッチ操作

  • 2本指でピンチ: 拡大・縮小、回転、移動
  • 2本指タップ: 元に戻す
  • 3本指タップ: やり直す
  • 長押し: スポイト
  • ペンを使うと、指は移動と拡大だけに使われます(メニューで変更できます)

キーボード

  • B ブラシ / E 消しゴム / S ぼかし / G バケツ / I スポイト
  • L 直線 / U 四角形 / O 楕円 / H 移動
  • [ ] ブラシサイズ / R・Shift+R 回転
  • Space を押しながらドラッグ: 移動
  • Alt を押しながらクリック: スポイト
  • ホイール: 拡大・縮小 / Ctrl+0: 画面に合わせる
  • Ctrl+Z 元に戻す / Ctrl+Shift+Z・Ctrl+Y やり直す
  • Ctrl+S プロジェクトを保存 / Ctrl+O プロジェクトを開く

画像の取り込み・変形

  • メニューの「画像を取り込む」で画像を選び、配置先を選んで確定します
  • 画像の内側をドラッグ: 移動 / 角: 拡大・縮小 / 外側か上の丸: 回転
  • Enter: 確定 / Esc: キャンセル
  • レイヤーの「変形」ボタンで、配置したあとも大きさと向きを変えられます
